# Vacatina Official Logo Pack v2

This pack contains the approved Vacatina logo assets supplied by Vacatina and normalized filenames for digital implementation.

## Critical brand rule

**Do not remove the tagline from any supplied full-logo lockup.**

The full Vacatina logo must be used as supplied, including the tagline **“we treasure your holidays”**. Do not create a wordmark-only or no-tagline derivative unless Vacatina later supplies that derivative as an officially approved asset.

When a full logo cannot remain legible because of limited space, use one of the supplied official standalone Vacatina marks instead. The standalone mark may be used proportionately for compact digital contexts, but it does not replace the main full logo where the full identity can be presented appropriately.

## Official brand colors

- Space Cadet — `#1B1464` — RGB `27, 20, 100`
- French Blue — `#0071BC` — RGB `0, 113, 188`
- White — `#FFFFFF` — RGB `255, 255, 255`
- Black — `#000000` — RGB `0, 0, 0`

Do not recolor official logo artwork outside the supplied approved variants.

## Web / app usage

### Desktop header
Use the full official logo only when it remains fully legible, including the tagline, without crowding navigation or account controls. Otherwise use `Vacatina_Mark_SpaceCadet.png` rather than modifying the full logo.

### Mobile header
Prefer the official standalone Space Cadet mark when the full logo cannot remain comfortably legible. The logo must never push the hamburger, Trip Bucket, or other critical controls outside the viewport.

### Footer
Use an appropriate full official logo with tagline. Use the primary full-color version on light backgrounds and an approved reverse version on dark backgrounds.

### Favicon / app / social avatar
Use the official standalone mark, normally `Vacatina_Mark_SpaceCadet.png`.

## Clear space
Maintain protected breathing room around the logo. Project brand documentation defines the minimum clear space around the full logo using the width of the lowercase `n` in the official Vacatina wordmark as the reference unit. More clear space is acceptable; less is not.

## Never

- remove the tagline from a supplied full-logo asset
- redraw the Vacatina wordmark
- rebuild the aircraft mark with generic SVG geometry
- stretch or compress the logo
- rotate or mirror the logo
- recolor or change saturation
- add drop shadows, glow, outlines, bevels or gradients
- use CSS filters to manufacture a new color variant
- ask AI image generation to recreate the Vacatina logo
- create a no-tagline wordmark derivative unless Vacatina supplies an approved one

## Source preservation
The `source-originals/` folder preserves the supplied source PNG files under their original upload names.
